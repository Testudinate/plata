# Приложение I — Оценка текущего уровня зрелости

*Перевод. Оригинал: [../Test Assignment - Appendices/Appendix I - Maturity Assessment.md](../Test%20Assignment%20-%20Appendices/Appendix%20I%20-%20Maturity%20Assessment.md)*

## Рамка оценки

Зрелость data governance в Plata оценивается по фреймворку DAMA DMBoK. Из 11 дисциплин DMBoK шесть отслеживаются активно:

- Change Management
- Data Catalog Management
- Reference Data Management
- Data Quality Management
- Data Architecture
- Master Data Management for Customer Data

Для этой роли наиболее значимы четыре измерения:

1. **Data Quality Management**
2. **Reference Data Management**
3. **Data Catalog Management**
4. **Change Management**

Каждое оценивается по лестнице из четырёх уровней: **Basic → Defined → Controlled → Continuing improvement**. Мы исходим из того, что вы понимаете, что означают эти уровни для каждой дисциплины; можете пользоваться определениями DMBoK или собственной рабочей трактовкой — главное, укажите, какой именно.

## Как пользоваться этим приложением

Для каждого из четырёх измерений:

1. Разместите Plata на одном из четырёх уровней, опираясь на свидетельства из Приложений A–H.
2. Приведите конкретные свидетельства (или их отсутствие), на которых основано ваше решение.
3. Там, где свидетельств мало или они неоднозначны, скажите об этом прямо и опишите, что бы вы хотели собрать для подтверждения.
