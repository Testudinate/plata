# snowflake-sandbox

Песочница в Snowflake, воспроизводящая ландшафт данных из `Test Assignment - Appendices`
(A–H): те же базы, схемы, таблицы, зерна (grain), соглашения о знаках и те же «грабли».

## Зачем

Тестовое задание (Parts 1–5) написано про данные, которых у нас нет. Ответ, в котором
три расчёта COR за апрель — это реальные три числа из реальных таблиц, а «канонический
метрик-слой», «DQ-мониторинг» и «контекст-слой для LLM» — работающие объекты, а не
слайд, отличается от текстового эссе на порядок. Песочница — фундамент под такой ответ.

### Кто что запускает

`sql/00_bootstrap_accountadmin.sql` — **единственный** файл для ручного запуска,
и только под `ACCOUNTADMIN`: сессия MCP закреплена за `HERMES_MCP_ROLE`,
`USE ROLE` в ней запрещён, а `CREATE DATABASE`, `CREATE ROLE` и гранты на
аккаунте требуют админа.

Все остальные скрипты (`01`, `02`, дальше) выполняет рабочая сессия под
`HERMES_MCP_ROLE`. **Под `ACCOUNTADMIN` они упадут** с `Insufficient privileges
... must have CREATE SCHEMA granted on DATABASE ODS` — после фазы 0 базами
владеет `HERMES_MCP_ROLE`, и вместе с владением у админа ушло право создавать
в них схемы. Так и задумано: у объекта один владелец. При необходимости
`ACCOUNTADMIN` выдаёт себе доступ сам (`GRANT CREATE SCHEMA ON DATABASE ODS TO
ROLE ACCOUNTADMIN`) — запереть себя из аккаунта передачей владения нельзя.

## Целевой аккаунт

Проверено фактическими запросами 2026-08-12:

- аккаунт `DX31435`, регион `AWS_AP_SOUTH_1`, версия 10.28
- сессия MCP закреплена за ролью `HERMES_MCP_ROLE`, `USE ROLE` запрещён
- у роли есть: `CREATE SCHEMA` на `HERMES_MCP`, `USAGE`+`OPERATE` на `COMPUTE_WH`
- `CREATE DATABASE` на аккаунте — **нет**
- edition не ниже Enterprise: `CREATE TAG` проходит, системные DMF
  (`SNOWFLAKE.CORE.FRESHNESS`, `NULL_COUNT`, `DUPLICATE_COUNT`,
  `REFERENTIAL_INTEGRITY_COUNT`, `ROW_COUNT`, ...) доступны
- у роли есть `USAGE` на `CORTEX_AGENT_SERVER` — путь к семантическому слою для агента открыт
- пользователь `ANASTAS` имеет `ACCOUNTADMIN` и `ORGADMIN` — одноразовые гранты
  выдаются им вручную через Snowsight
